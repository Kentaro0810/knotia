# Knotia 第1版 v1.2.0

**つながる。話せる。共有できる。**

Knotiaは、管理者承認制の共同コミュニケーションWebアプリです。

## 実装済み
- 本名・表示名・メール・パスワードによる利用申請
- 承認待ち／承認済み／却下／利用停止
- Kentaro0810専用管理者画面
- 日付・曜日・時刻・時間帯別挨拶のホーム
- 利用者一覧
- みんなの掲示板（リアルタイム）
- 1対1個人チャット（当事者だけが閲覧可能）
- 複数の共有メモ、変更履歴、削除・復元
- 共有リンク場
- 通知
- マイページ
- SecretLinksへの入口
- 利用規約・プライバシーポリシー原案
- PWA・ホーム画面アイコン

## 公開に必要なもの
- GitHub Pages
- Supabase Auth / Database / Realtime / Edge Functions
- 承認結果メールを使う場合はResend

詳しい設定は `Supabase設定手順.md` と `GitHub公開手順.md` を参照してください。
